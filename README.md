# Notes

A locally running desktop app for Windows that includes notes, tasks, a calendar, and diagrams.

## Features

- Local note management
- Task list
- Calendar with notes
- Multi-diagram workspace
- Local backup
- No account or internet connection required

## Download

You can download the latest Windows installer from the Releases section.

## System Requirements

- Windows 10/11
- 64-bit
